# Scrum Gromming Poker

A planning poker app for scrum teams to estimate stories together.

## Structure

- `backend/` - NestJS API
- `frontend/` - React + Vite client

## Getting started

Requires Node.js and pnpm.

```bash
# backend
cd backend
pnpm install
pnpm start:dev

# frontend
cd frontend
pnpm install
pnpm dev
```
